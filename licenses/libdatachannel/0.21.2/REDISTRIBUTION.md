This package contains libdatachannel 0.21.2 and libjuice under MPL-2.0, plog and nlohmann/json under MIT, usrsctp and libsrtp under BSD-3-Clause, OpenSSL 3.3.2 under Apache-2.0, and selected GCC/MinGW runtime components with their accompanying notices.

MPL source availability: the exact, unmodified commit-addressed source archives for libdatachannel and libjuice are included under sources/ in this same ZIP at no additional charge. All five dependency source archives are also included, preserving their copyright and license notices. sources/source-manifest.json gives repository commits, final URLs, retrieval times, SHA-256 and byte lengths. Extract the parent archive, then each dependency archive into deps/<name> with the top directory stripped. The covered source remains available under MPL-2.0, including all rights provided by that license. No restrictions are imposed on recipients' rights in the covered source.

Only libgcc_s_seh-1.dll and libstdc++-6.dll from gcc-libs are redistributed. The GCC Runtime Library Exception 3.1 applies to their combination with independently built target code produced by the eligible GCC compilation process. libquadmath and the compiler are not in the package. libwinpthread is distributed with its MIT/BSD notices. MinGW CRT/header notices are included for linked startup/runtime code. OpenSSL's bundled license is retained; its DLLs are unmodified signed-package contents (the package signature is OpenPGP, not Authenticode).

No source edits were made. CMake generated include/rtc/version.h from the upstream template, and the exact generated header is also included under sources/generated/. Build configuration: MinGW Makefiles, Release, GCC 14.2.0-1, OpenSSL 3.3.2-1, shared datachannel with bundled static usrsctp/libsrtp/libjuice, NO_TESTS=ON, NO_EXAMPLES=ON, USE_GNUTLS=0, USE_NICE=0. sources/build-configuration.json records the compiler options and layout using the stable virtual workspace /workspace/libdatachannel. GCC canonical file/debug prefix maps map the entire local workspace to /build/libdatachannel-work, including source, dependency sources, build outputs and staged compiler headers. Local machine paths are retained only in private worker logs. Upstream tests were disabled as required; the packaged library was checked with a separate clean consumer.
